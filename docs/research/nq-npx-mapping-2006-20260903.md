## Structural parser issues identified

Confirmed non-performance issues include:
- N-PX placeholder ticker text such as `N/A` could previously be reduced to `N`;
- issuer names can differ only by leading/trailing `THE`;
- two collision-tested lexical equivalences are safe on the frozen master: `HLDGS` ↔ `HOLDINGS` and `PHARMACEUTICALS` ↔ `PHARMACEUTICAL`.

Automatic fuzzy matches remain prohibited.

## Index transport findings

The original Notre Dame/Google Drive master-index archive previously returned a ~345 MB ZIP but later returned a ~2 KB HTML response in GitHub Actions.

Official SEC EDGAR quarterly `master.idx` requests from GitHub-hosted runners return HTTP 403. A `r.jina.ai` transport attempt for the index returned HTTP 422.

Official SEC quarterly `master.zip` was then tested separately in run `33708602968`. It also returned HTTP 403 from GitHub-hosted runners, including four retries on QTR1. Therefore changing from `master.idx` to `master.zip` does not solve the GitHub-runner transport restriction.

This is a source-transport limitation, not evidence that the SEC historical index is absent. The 64-CIK design remains frozen and pending a reproducible index-input path.
