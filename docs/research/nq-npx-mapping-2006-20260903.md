Date: 2026-09-03 JST

## Purpose

Measure whether legacy N-Q PIT holdings can support a faithful historical ETF-holdings universe using a free N-PX-derived issuer/ticker/security-id master, without using return or strategy-performance information.

## Anti-overfitting rule

All parser, series-assignment and security-mapping changes in this workstream are based only on filing structure, issuer text and security identifiers. Fuzzy candidates are diagnostic only. No CAGR, returns, trades or Stage21 outcomes are used to choose rules.

## 3. Critical N-Q series-assignment correction

Root cause:
- the old parser began each block at the generic `Schedule of Investments` marker;
- legacy N-Q filings frequently place the actual fund/series heading immediately before that marker;
- mapping from text only after the marker could therefore shift a holdings block to a neighboring series.

Correction:
- use a tight context window spanning 5,000 characters before and 2,500 characters after the schedule marker;
- prefer an exact filing-time series-name phrase;
- reject exact ties and near-ties instead of forcing an assignment;
- apply the identical rule to both segmentation and PIT holdings construction.

## 5. Conservative legal-name aliases

Residual diagnostics show that many misses are formatting differences rather than missing securities, including:
- leading/trailing `THE`
- `Companies` vs `Cos.`
- share-class labels such as `(Class A)`
- trailing ADR/GDR labels
- N-Q footnote markers
- common Bancorp/Bancorporation spelling variants

A second mapping layer was therefore added using only these legal/display-name transformations. It still accepts a mapping only when the transformed issuer key points to one unique N-PX `(ticker, securityId)` identity. Fuzzy candidates remain diagnostic-only.

## 6. Remaining mapping gap

The remaining gap is no longer dominated by generic fuzzy-name mismatches. Two distinct classes remain:

1. **N-PX ticker-only evidence**
   Some exact issuer records contain a historical ticker but no parsed security ID, e.g. Comcast, UNUM, PNC, Janus, KeyCorp, Sun Microsystems and Sigma-Aldrich. These should be measured separately as lower-confidence Tier B evidence rather than silently discarded or promoted to Tier A.

2. **True identity ambiguity / foreign depositary structures**
   ADR/global names can have several N-PX identities for the same issuer, e.g. HSBC, Toyota, Novartis, Vodafone, Shell, Siemens and Barclays. These remain unresolved unless filing structure supplies a deterministic security-level discriminator. Do not choose an identity using price availability or strategy performance.
