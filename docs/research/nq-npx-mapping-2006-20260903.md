## 4. Structural proxy for N-PORT US/CORP/EC

Legacy filings do not expose modern N-PORT classification fields directly. The proxy therefore uses only explicit structure:

- require Tier A or Tier B identity;
- ADR/GDR/depositary receipt -> `NON_US_PROXY`;
- debt/preferred/options/warrants/rights -> `NON_EC_PROXY`;
- LP/limited partnership/LLC -> `NON_CORP_PROXY`;
- do not infer domicile from company-name spelling or ticker;
- otherwise retain as `LEGACY_EQUITY_CANDIDATE`.

## 5. Frozen structural gates

### Gate A — historical security mapping

PASS only if:
- aggregate Tier A+B eligible-weight coverage >= **85%**;
- median retained-series Tier A+B weight coverage >= **85%**;
- semantic schedule-to-series audit has zero failures;
- no fuzzy/header-token match is promoted automatically.

The corrected 2006 pilot clears the aggregate coverage requirement and remains the current identity baseline.

### Gate B — shared-series legacy vs N-PORT fidelity

Use 2020 N-CSR/N-CSRS and N-PORT for the same SEC `seriesId`, with nearby report dates.

The current implementation is `scripts/research-legacy-universe-reproducibility-2020.py`.

PASS requires:
- at least **10** paired series;
- median legacy symbol-weight coverage >= **80%**;
- Top80 overlap >= **80%**;
- common-Top80 rank correlation >= **0.80**;
- N-PORT Top2 retention >= **90%**.

This gate isolates parser + issuer identity + Production-style scoring fidelity while holding the series set fixed.

### Gate C — missing-series impact

Compare full N-PORT against N-PORT restricted to the SEC series that the legacy pipeline can structurally reconstruct. Both sides use N-PORT holdings so parser/mapping error is removed.

PASS requires:
- Top80 overlap >= **80%**;
- common-Top80 rank correlation >= **0.80**;
- N-PORT Top2 retention >= **90%**.

Only Gate B + Gate C PASS permits the legacy bridge to be described as structurally equivalent to the Production universe.
