## 3. Security identity confidence tiers

Tier A:
- unique exact normalized issuer match;
- exactly one N-PX `(ticker, securityId)` identity.

Tier B:
- no Tier A identity exists;
- unique exact normalized issuer match;
- one structurally valid 2–5 character historical ticker;
- security ID absent.

Unresolved:
- multiple identities/tickers;
- no structural match;
- parser/header ticker token;
- single-character ticker-only evidence;
- fuzzy similarity only.

## 5. Fidelity gates frozen before long-history performance

The following thresholds are fixed before any 2006–2018 Stage21 performance run.

### Gate A — historical security mapping

PASS only if:
- aggregate Tier A+B eligible-weight coverage >= **85%**;
- median retained-series Tier A+B weight coverage >= **85%**;
- semantic schedule-to-series audit has **zero failures**;
- no fuzzy match is promoted automatically.

Current 2006 pilot is expected to satisfy Gate A; the workflow result is the source of truth.

### Gate B — direct legacy filing vs N-PORT holdings overlap

Use 2020 N-CSR/N-CSRS and N-PORT for the same SEC `seriesId`, with report dates no more than 45 days apart.

PASS only if:
- at least **10** usable same-series comparisons exist;
- median legacy holding weight covered by normalized N-PORT issuer names >= **80%**;
- median N-PORT holding weight covered by normalized legacy issuer names >= **80%**.

Interpretation:
- >=80% median both directions: continue;
- 60–80%: improve parser/structural mapping using filing evidence only, then rerun;
- <60% either direction: reject the current legacy bridge.

### Gate C — universe-level fidelity

After Gate B passes, build the legacy universe using the same economic inputs as production where available:
- distinct ETF count;
- aggregate holding weight;
- maximum holding weight;
- filing-recency-weighted holding weight;
- production score `3*log1p(etfCount) + 0.5*log1p(aggregateWeight) + 0.5*log1p(recencyWeight)`;
- production eligibility `etfCount >= 2 OR maxWeight >= 4`;
- Top80.

On a genuine N-CSR/N-PORT overlap sample, PASS only if:
- median Top80 set overlap >= **60%**;
- median Spearman rank correlation over common Top80 names >= **0.60**;
- frozen production monthly selected-symbol retention >= **70%**;
- months with both production Top2 symbols retained >= **50%**.

These are fidelity thresholds, not return thresholds. They must not be changed after seeing 2006–2018 strategy performance.
