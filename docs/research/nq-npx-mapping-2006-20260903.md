## Structural parser issues identified

Two non-performance issues were confirmed:

1. Some N-PX records expose placeholder ticker text such as `N/A`. The old regex could reduce this to `N`, creating a false ticker identity.
2. Issuer names can differ only by leading/trailing `THE`, e.g. `PROCTER AND GAMBLE CO THE` vs `Procter & Gamble Co.`.

Automatic fuzzy matches remain prohibited. ADR suffixes are not stripped because an ADR and an ordinary share can be distinct securities.

## Data transport issue

The original Notre Dame/Google Drive master-index archive previously returned a ~345 MB ZIP but began returning a ~2 KB HTML response in GitHub Actions.

Official SEC EDGAR quarterly `master.idx` files exist and are the preferred source, but direct requests from GitHub-hosted runners currently receive HTTP 403. Research scripts now attempt the official SEC URL first and a `r.jina.ai` transport of the same official URL second. The economic/source data remain SEC EDGAR; the proxy is transport only.

The frozen successful artifacts are retained and a separate remap workflow allows mapping-rule validation without conflating it with current source-transport failures.
