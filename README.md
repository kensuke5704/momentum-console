# Momentum Console

Google スプレッドシートと Apps Script で運用していたモメンタム投資モデルを、PC向けのWebアプリとして再実装したものです。

## 主な機能

- QQQの10か月移動平均による RiskOn / Cash 判定
- 現在のシグナルは当月途中値を除外し、直近の確定月末価格で判定
- 1か月、3か月、6か月の相対モメンタム計算
- QQQスコア比較、急騰除外、テーマ別上限による銘柄選定
- 採用候補が目標銘柄数に満たない月は全額現金
- 目標配分と実保有株数の差額計算
- 月次バックテスト、CAGR、ボラティリティ、最大ドローダウン
- 既存銘柄の出し入れと銘柄コードによる新規候補の追加
- 直近24か月の採用履歴による整理候補の抽出
- 戦略条件の変更とブラウザ内再計算

## データ更新

GitHub Actionsが米国市場営業日の朝にYahoo Financeの公開データを取得し、静的データファイルを再生成してGitHub Pagesへデプロイします。Actions画面から手動実行することもできます。

画面右上の「価格を更新」ではApps Scriptプロキシを介して既存銘柄の最新価格を一括取得します。候補比較で入力した新規銘柄も、同じYahoo Financeの調整後終値を参照します。売買判定には当月途中の価格を使わず、直近の確定月末価格を使用します。

```bash
npm run dev
```
