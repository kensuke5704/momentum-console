# Repository Agent Instructions

## Canonical Momentum research handoff

The canonical handoff for ongoing Momentum strategy research is:

`docs/research/momentum-handoff-current.md`

For any change on the Momentum research line that materially changes research code, validation status, assumptions, conclusions, workflow/run state, rejected approaches, or next actions:

1. Read the handoff before making the change.
2. Update the handoff in the same change set whenever possible.
3. Record decisive metrics, workflow run IDs, commit SHAs, failures, and conclusions.
4. Keep the `Current active gate` and `Planned validation sequence` current.
5. Do not modify the frozen Stage21 production strategy while performing historical-reconstruction research.

A research change is not considered fully documented until the handoff reflects it.
